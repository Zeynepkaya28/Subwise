💳 Subscription & Expense Tracker

A web-based platform that allows users to manage and monitor all their monthly subscriptions in one place. Users can view active memberships, cancel unwanted subscriptions, and analyze their spending habits with detailed statistics and visual reports.

🚀 Features
📋 View all active monthly subscriptions in one dashboard
❌ Cancel subscriptions easily
💰 Track total monthly spending
📊 Visual breakdown of expenses by category
📉 Spending reduction and trend analysis charts
🔔 Subscription monitoring and status tracking
👤 User-based personalized dashboard


🧠 Key Benefits
Helps users reduce unnecessary subscription costs
Provides clear insight into monthly financial habits
Encourages smarter financial decision making
Centralizes all subscriptions in a single platform

🛠️ Tech Stack

(You can update this part based on your project)

Frontend: React / Next.js
Backend: Node.js / NestJS
Database: MongoDB / PostgreSQL
Charts: Chart.js / Recharts
Authentication: JWT / OAuth

📦 Installation

# Clone the repository
git clone https://github.com/zeynepkaya28/Subwise.git

# Navigate to project directory
cd subscription-tracker

# Install dependencies
npm install

# Start development server
npm run dev
